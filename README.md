# Dobot 分注プランナー

GitHub Pages: 96ウェル版は `index.html`、30本試験管・複数ソース版は `testtube.html` です。

## 試験管版の準備

1. 既存のDobot制御フォルダに `web_control.py`、`main.py`、`web_worker.py` と現在使用中のconfig・commands・DLL・制御ライブラリがあることを確認します。制御コードはこのWebページのリポジトリには含まれていません。
2. `windows` フォルダから `launch_web_control.ps1`、`register_dobot_protocol.ps1`、`register_dobot_protocol.bat` を同じフォルダへコピーします。
3. `register_dobot_protocol.bat` を一度実行します。Windowsの現在のユーザーだけに `dobot://` 起動リンクを登録します。管理者権限は不要です。再配置した場合は登録BATを再実行してください。
4. ロボット制御用Windows PCで `testtube.html` を開き、「接続キーを発行」を押します。ブラウザーの確認が出たらPowerShellの起動を許可してください。PowerShellに表示されたキーをページへ貼り付け「PCへ接続」を押します。Webページと `web_control.py` は同じPCで動作させます。

## 分注の流れ

1. CSV欄の「記入例」または手入力で `source,destination,volume_ul` を作成します。例の順番は、記入例→テキスト欄→CSV保存→ファイル選択→CSV読み取りです。ファイル選択はテキスト欄へ内容を読み込むだけなので、読み取りボタンを押してください。
2. ソース名は `Co, Ni, Cu, Ru, Rh, Pd, Ir, Ag, Pt, Au` のいずれかです。分注先は `tube1`〜`tube30`、液量はµLです。
3. CSV読取後に表示される各ソースの必要量を確認し、同じ位置に置く50 mL遠沈管の初期液量を入力します。
4. 「CSV検証」を押すと、計画をPCへ保存して検証します。高さ・速度・ポートの設定は既存の試験管用計画を引き継ぎます。「実機で開始」は検証成功後に使えます。
5. CSVの行順で分注します。ソースの交換が必要な時は音で通知し、容器とチップを手で交換して「準備完了・続行」を押します。分注が正常終了した時も音が鳴ります。ブラウザーで音を鳴らすには、操作前にページ上のボタンを押しておく必要があります。

```csv
source,destination,volume_ul
Co,tube1,100
Co,tube2,500
Ni,tube4,300
```

## 座標・安全事項

config/testtube.csv に `name,x,y` 列と tube1〜tube30 の実座標が必要です。10本分から残りの座標を推定しません。校正点は tube1、tube10、tube21、tube30 です。4点のXYから回転・平行移動を求めます。参照点はラックの二次元方向に広がる必要があります。校正ずれや液量不足は実行前に停止します。

初期量の設定と必要量の計算はµLです。CSVが同じソースを後半で再び使う場合、計算上の残量を引き継ぎます。途中で補充する計画は分けてください。試験管の許容液量は操作者が確認してください。

停止要求は機器操作の区切りで反映され、即時の非常停止ではありません。ブラウザーを閉じてもPC側の処理は止まりません。中断後の自動再開はしません。ログと結果CSVはPC側の既存logsに保存されます。
