# Dobot 分注プランナー

96ウェル版に、CSVで複数ソースを30本の試験管へ分注する画面を追加しました。

## 更新・操作

1. `windows` 内の main.py、web_control.py、web_worker.py を、現在使っている分注フォルダにコピーします。以前のファイルは控えを残してください。既存config、commands、DLL、制御ライブラリを使用します。
2. GitHub側の index.html を更新します。
3. PowerShellで `python web_control.py` を起動し、Webページへ接続キーを入力します。BATは不要です。
4. 30本試験管の欄でCSVを読み込み、各ソースの吸引位置・容器登録と実際の初期量を入力します。同じ場所で手動交換する場合は同じ登録を選べます。
5. 既存の試験管用計画CSVを選んでPCへ保存し、「CSVを検証」後に開始します。高さ・速度・ポートは選択した計画を引き継ぎます。

```csv
source,destination,volume_ul
ソース1,tube1,100
ソース1,tube2,500
ソース2,tube4,300
```

source_id 列も source の代わりに使えます。CSVの行順を維持します。ソース名が変わると安全高さまで上げ、Windows PCで音を鳴らして停止します。容器とチップを交換し「準備完了・続行」を押してください。新しいチップでソース上方と液面を取り直します。最初のソースの準備時にも音が鳴ります。「通知音を試す」でブラウザ側の音も有効になります。

同じソースが後半に再び現れた場合、そのソースの計算上の残量を引き継ぎます。途中で補充する場合は計画を分けてください。チップ容量を超える量は分割します。試験管の許容液量は操作者が確認してください。

## 座標と校正

config/testtube.csv に name,x,y 列と tube1〜tube30 の実際の配置座標が必要です。10本分から推測して増やしません。

校正点は tube1、tube10、tube21、tube30。4点の中心XYから回転・平行移動を求めます。参照点はラックの二次元方向に広がる必要があります。校正ずれが既存計画の許容値を超えた場合は停止します。吐出Zは既存計画の固定設定です。

停止要求は機器操作の区切りで反映され、即時の非常停止ではありません。ログと結果CSVは既存logsに保存します。中断後の自動再開はしません。

## 検証

実機未接続で、ソース順序、同一ソース再使用時の残量、容量分割、4点XY校正、校正ずれ・液量不足の拒否を確認しました。実機動作は未検証です。
